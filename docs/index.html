How to install

  1. Tap Download. If your phone asks, allow your browser to install apps.
  2. Open the downloaded file and tap Install. If a Google Play Protect warning appears, tap "More details", then "Install anyway".
  3. Open MessMate. New here? Tap "Activate account or forgot password?" and use the email the PG office has for you.

Updating? Download the same file and install it over the old app. Your account stays.
